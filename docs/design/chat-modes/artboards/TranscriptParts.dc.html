The chat switches Focus to Team when a second agent starts working and back when it is alone again, without moving your scroll. Pinning a view stops that.
What reaches the thread
Always in the thread
your messages, what an agent says to you, questions, approvals, results, errors that stopped work
Folded to one line
tool calls of a finished turn, handoffs between agents, agent-to-agent talk
Updated in place
an agent’s work card while it runs; it never appends a line per step
Only when asked
reasoning, raw input and output (Raw, or Full output on a step), the full log in Session
How an output excerpt is picked
1
Lines matching error, failed, cannot, exception, or a non-zero exit, with one line of context
2
Else the last 3 lines
3
At most 8 lines, never wider than the card; the rest is behind Full output
4
Exit code and how the lines were picked are always said under the excerpt
