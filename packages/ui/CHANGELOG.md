# Changelog

All notable changes to `@agentic/ui` (Keep a Changelog, semver).

## [Unreleased]

- `AgentForm` gains a `workdir` slot (`AgentFormWorkdirProps { environmentId, path, set }`) under "Default environment", and `AgentDraft.defaultWorkdir` posts as `AGENT_FIELDS.workdir` (#193).
  - A folder picked through `set` also sets the default environment; choosing another environment in the select clears the folder.
  - `fromAgentDraft` keeps `execution.defaultWorkdir` only with a default environment.
- Working-folder picker (#191; new `ag-workdir` / `ag-workdir-picker` scopes, `AgWorkdir` / `AgWorkdirPicker`). `WorkdirField` shows the chip `machine / environment · …\last\two` with the full path in `title`, plus "Change…" (`open`) and "Clear" (`clear`) inside a `Field.Root`. Its `name` posts `${name}.environmentId` / `${name}.path` as hidden inputs; `compact` renders the chip alone as a button for a chat header. `WorkdirDialog` is a controlled, plain zero `Dialog` (not an alert dialog). It has an environment strip where an unavailable environment is disabled with its reason visible, and a top level of Recent and Roots. Inside a folder it shows a breadcrumb from the root down, with All roots above it; an "Edit path" editor checked with core `pathWithin`; the folder's git badge; and a folder `listbox` (click or Enter drills in, arrows / Home / End move, Backspace goes up, and Backspace at a root returns to the top level). Its states are loading (a skeleton, or the stale listing dimmed through the `loading` modifier), empty, truncated, and an error in plain text per `FsErrorCode` with "Try again". The inline "New worktree…" form offers branch, base and target; the target follows `suggestWorktreePath` until it is edited, and submitting emits `createWorktree`. The footer has Cancel and "Use this folder", which emits `select` and closes; Escape or the backdrop emits `cancel`. The dialog contains no `<form>` and no named controls. Pure helpers: `workdirLabel`, `workdirCrumbs`, `middleTruncate`, `fsErrorText` / `FS_ERROR_TEXT`, `gitBadgeText`, `samePath`, `toWorkdirEnvironment` (from `EnvironmentDescriptor` + machine via `environmentStatus()`). New icons `folder` and `branch`. The picker's popup is 640 px wide and border-box, so it keeps the 16 px gutter at phone width (signalxjs/zero#101).
- Composer attachments and media parts (#208, CHT-10). `Composer` takes files three ways — the Attach button now opens a hidden `<input type=file multiple>` (`accept` prop; `attach` still fires), a paste carrying `clipboardData.files` (plain text pastes as before), and drag-and-drop onto the card (the root carries the governed `highlighted` flag while a drag with files hovers) — and all three emit a new `files` event with a `File[]`; it never uploads. `Attachment` gains `status` (`uploading` | `ready` | `error`, as `data-state` `loading` | `complete` | `error`), `error` and `previewUrl`; a chip shows the thumbnail or a file icon, name, size, a spinner while uploading, the error line, and a `Remove <name>` icon button (`removeAttachment` unchanged). Send is disabled while any chip is uploading and sends with an empty draft when there are attachments (`send` emits `''`). New `ai-composer` parts `thumbnail`, `attachment-name`, `attachment-size`, `spinner`, `attachment-error`; `AttachmentStatus` and `ATTACHMENT_STATE` exported. `prepareImage(file, { maxEdge = 1568, quality = 0.85 })` downscales with `createImageBitmap` + `OffscreenCanvas` (or a `<canvas>`), re-encodes as WebP (JPEG where WebP cannot be written) only when smaller, leaves GIF / SVG / non-images alone and returns the original on any failure. `Message` renders an `image` part as a lazy thumbnail (at most 320 px) linking to the full size in a new tab, and a `file` part as a download chip (icon, name, size) — new `ai-message` parts `image`, `file`, `file-name`, `file-size`. `fragmentCss` gains the `ai-spin` keyframes. The `@agentic/ui` size budget moves to 68 KB.
- `QuestionPrompt` (#194; `AiQuestion`, new `ai-question` scope): an open input request as a question card — one `question` per form property (`label`, `prompt`, the options as `on`/`off` toggles with a `hint`, a free-text `other`), `actions`, `error`, `record`. A request with a `schema` (Claude Code's `AskUserQuestion`: `q1`, `q2`, …, a multi-select as an array) answers with an object keyed by property — the runtime drops a bare string as "The user did not answer the questions." — and one without (the platform's `ask_user`) with the text. `ToolCall` renders it on the call that asked, and `looseRequests` / `Thread` now include input requests with no call of their own; before, the chat had no card for a question at all. `questionFields`, `questionAnswers`, `answerText` exported.
- Fixed (#177): the agent form's Approval policy hint for the read category named `memory.search`; the platform tool is `memory_search`.
- `ApprovalPrompt` (#40): `onRespond` may return a promise — the buttons stay disabled while it is out, a rejection re-enables them and shows `Could not answer: …` (`description`, `role="alert"`), and a resolution leaves them disabled until the `decision` prop arrives — from this client or another. `RespondFn` returns `unknown`.
- Responsive and mobile pass (#91), `docs/design/HANDOFF.md` → "Responsive behaviour", "Mobile specifics". Shell: below 768 px the bar is a 60 px app bar on base-200 — `AppShell` gains `title` (the page), `back` (a detail route's parent; the `back` slot renders the router's link around the arrow), the `subtitle` slot (member tiles, a status summary) and the `phoneAction` slot (the one right slot; without it the last action shows) — and the drawer is 312 px on a near-black scrim with a brand + 44 px close head (`drawer-head`), 50 px items with 16 px labels and 20 px icons, the connection strip at its foot, a 200 ms slide that is off under reduced motion. `NavItem` gains `icon` (the kit's glyph, 17 px in the sidebar; the `link` slot receives it as `icon`). The breadcrumb is one line with an ellipsis on the entity. Kit: `DataTable` wraps its table in `[data-ag-table]` carrying each column head as `--ag-col-N`; below 768 px the kit CSS stacks every row into a card with captioned cells (no second markup, so the server render never guesses the viewport), and between 768 and 1279 px the drawn column widths yield and a wider table scrolls inside its own box. Buttons never wrap their label; below 768 px they are 48 px (icon buttons 48 square) and split an action row evenly; `EnvironmentCard` folds to a 52 px row (name + auth pill, runtime and capacity, default tiles); `EnvironmentLine` gains `fit="drop-machine"` (the machine segment hides below 768 px, the `title` keeps all three); new icons `back` and `tree`. Fragment: below 768 px the composer docks as one row — attach 48, single-line input 48 at 15 px on base-100, a square primary Send — under the "To" row with `env(safe-area-inset-bottom)`; the message meta drops the environment line (the approval card keeps it); the approval card's `Allow once` takes a full row and the other two share the next at 48 px, the session answer reading "Allow for session" (`label-full` / `label-short` parts; the accessible name stays "Allow for this session"). The composer's field fills its card and its label is visually hidden; the textarea no longer renders at its intrinsic width.

- Thread (#88): `describeRequest` on `Thread` / `Message` / `ToolCall` (`DescribeRequestFn` → `ApprovalContext`, the `ApprovalPrompt` props a page knows and the transcript does not: `toolName`, `input`, `rule`, `requestedBy`, `environment`, `via`, `decision`, `compact`), so the approval card inside a tool call — or a loose request — renders its context rows.
- `AgentForm` layouts (#89), `docs/design/HANDOFF.md` → Agent config: `layout="sections"` renders every section as a two-column row (a visually hidden `legend` still names the fieldset; a `section-head` with `section-heading` + `section-hint` beside the `section-body`), and moves saving into the `rail` slot — rendered inside the `<form>` so the reason still posts — which receives the form API plus the bound `config` (`AgentFormRailProps`); the default Save section is not rendered when the slot is given. `approvalControl="segmented"` renders allow / ask / deny per category as a kit `Segmented` (`policy-row` / `policy-label`) posting through a hidden input under the same field name. `dirty()` joins the exposed API. The stack layout and the field names are unchanged.

- States (`src/kit/states`, #87), `docs/design/HANDOFF.md` → "Failure distinction", "Edge cases": three more `ag-*` scopes — `ag-failure` (`FailureCard`, the six named states from the shared `FAILURES` table with name, icon, signal caption, tone and action; `kind` axis fully wired, `client-offline` → `offline`), `ag-banner` (`OfflineBanner`), `ag-empty` (`EmptyState`: workspace / inbox / machines / chat / generic; `compact`, `outline`) — plus `EventsLostRow`, the connection-strip row helpers (`browserRow`, `machineRow`, `connectionRows`) and the skeleton presets (`TableSkeleton`, `CardSkeleton`, `RailSkeleton`). Every declared axis value is now wired, so the web build validates with `--strict`.
- `ai-*` fragment restyled to `docs/design/HANDOFF.md` (#86): `ai-thread` (gap 24, padding 24/32, the "Showing the last N entries · Load earlier" chip, `aria-live="polite"`), `ai-message` as a row — kit `AgentTile` avatar (persons are circles), `meta` with new `name` / `environment` (kit `EnvironmentLine`) / `time` parts and the STREAMING pill on the last assistant row mid-turn; `Thread` gains `describe`, `toolMeta`, `logHref`; `Message` gains `author` (`MessageAuthor`), `streaming`, `toolMeta`, `logHref`; `midTurn` exported. `ai-tool-call` header with `icon` (`toolIcon`), `name`, `signature`, `meta`, the phase as a `StatusPill` (PENDING · RUNNING · DONE · ERROR · DENIED; refined phase in `meta`), a border colour only for `active` / `error`, the output well folded past `OUTPUT_FOLD` (6) lines behind `more` and linking to the session `log` past `OUTPUT_LOG` (200); `ToolCall` gains `meta` and `logHref`; `elide` no longer folds lines. `ai-reasoning` collapsed as "Reasoning · Ns" behind a 14 px chevron (`seconds`, `reasoningSummary`). `ai-approval` as the approval card — `header` (`title`, `rule`), `request` well, `context` rows, three `actions` (`Allow once` amber, `Allow for this session`, `Deny`), `record` (`decisionText`), `compact` modifier, assertive announcement, buttons disabled and spinning until the ack; `ApprovalPrompt` gains `input`, `rule`, `requestedBy`, `environment`, `via`, `compact`, `decision` and drops the "Deny for session" button. `ai-composer` with the `addressing` row (`recipient` chips on `AgentTile`, `hint`, `NOBODY_HINT`), `keys` hint, an attach icon button (`attach` event), kit `Button`s (Send primary 44 px); `Composer` gains `recipients`, `hint`, `attach`. Recipes read the `--ag-*` inks with recommended fallbacks; `fragmentCss` (the streaming pulse keyframes) rides the design system's raw-CSS slot; motion off under reduced motion. `Message` no longer composes zero `Chat`.

- App component kit (`src/kit`, #85), `docs/design/HANDOFF.md` → "Components": eight `ag-*` scopes with anatomies and recipes in the fragment — `ag-pill` (`StatusPill` with one row per `TaskStatus`, machine, auth and tool phase in `PILLS`; `Tag`; `WaitReasonLine` / `waitText` in the literal core names), `ag-agent-tile` (`AgentTile`, `hueFor`, `monogramOf`; people are circles), `ag-env-line` (`EnvironmentLine`, never one part alone — EXE-06), `ag-needs-item` (`NeedsItem`, `kind` axis, `compact`), `ag-task-node` (`TaskNode`, depth rail, `selected`, a real button), `ag-connection` (`ConnectionStrip`), `ag-version` (`VersionItem`: current / proposed / past), `ag-env-card` (`EnvironmentCard` restyled: capacity meter, queued count, "Default for" tiles, auth fix line with `Re-check`; `authPill`, `authFixLine`; `environmentStatus` gains `tone`). Compositions over zero: `Button` (intents primary / default / wait / danger / icon on the daisy axes, `confirm`, `loading`, `block`), `Segmented` (ToggleGroup, `aria-pressed`, per-segment tone at 15 %), `Switch`, `ChipInput` (= `MultiSelect`), `DataTable` (column template → `<col>` widths, skeleton rows), `TimelineList`, `ConfirmDialog` (alert dialog, dependents listed, consequence label), `SectionHeading`, `Label`, `Icon` (the artboards' 34 stroke icons). Every `tone` and every kit modifier is wired; `tokens.scopes` claims the vocabulary per scope (`kitScopes`); `Ag*` aliases satisfy `componentExportName(scope)`. `kitCss` (`data-visually-hidden`) rides the design system's raw-CSS slot.

- Design system (`src/design-system`, `@agentic/ui/design-system`, #84): the `agentic` design system on zero-daisyui with the one dark theme `control-room` from `docs/design/HANDOFF.md`; `--ag-*` custom tokens; `tone` / `kind` axes and `hollow` / `outline` / `compact` / `selected` / `current` modifiers declared; daisy recipes re-tuned per scope by `withOverride` (button, fields, switch, badge, dialog, table, timeline, card, breadcrumbs, tabs, collapsible, toggle-group, skeleton, navbar); the `ai-*` fragment recipes included; compiled by `scripts/build-design-system.mjs` into `dist/ds/**` — exports `./css`, `./css/tokens`, `./register`, `./manifest.json`, `./fragment.json`; `installThemes()`. `@sigx/zero-daisyui` is a runtime dependency.
- App shell restyled to the handoff (#84): 232 px sidebar / 60 px topbar on the design-system tokens, nav `groups` (labelled `<nav>` per group) and per-item `badge`, `breadcrumb` / `actions` / `connection` / `user` slots, `flush` main, the 3 x 16 px live marker; `SHELL_BREAKPOINT` and `NavGroup` exported. The shell no longer renders `ThemeToggle`.

- Forms (`src/forms`, #25) on zero's `model=` form contract, each posting pre-hydration and read back by one parser: `AgentForm` (identity, skills/tools/connectors multi-select with a per-tool mode, per-category approval policy, memory, execution defaults and limits, collaborators, version reason; `submit` / `invalid` events, exposed `reset()` / `submit()`), `ConfigVersions` (history with revert, a real form per row), `EnvironmentCard` + `environmentStatus`, `SettingsForm` (IANA time zone, notification kinds, push, default environment). - Composer (`src/composer`, scope `ai-composer`): zero `Textarea` autogrowing by line count, Enter sends / Shift+Enter breaks, `@mention` listbox (arrows, Enter/Tab pick, Escape dismiss; the textarea is its combobox — `aria-controls` / `aria-expanded` / `aria-activedescendant` on stable option ids), attachments strip stub, Send gated on `busy`/`steers`, Cancel on `canCancel`.
- Fragment (`src/fragment`, `@agentic/ui/fragment`): the six anatomies as a manifest fragment (`version: 1`) plus a recipe pack on the recommended token grammar; `"sigx-zero"` package.json field; `build` also emits `dist/fragment.json`.
