# Changelog

All notable changes to `@agentic/ui` (Keep a Changelog, semver).

## [Unreleased]

- `AgentForm` layouts (#89), `docs/design/HANDOFF.md` → Agent config: `layout="sections"` renders every section as a two-column row (a visually hidden `legend` still names the fieldset; a `section-head` with `section-heading` + `section-hint` beside the `section-body`), and moves saving into the `rail` slot — rendered inside the `<form>` so the reason still posts — which receives the form API plus the bound `config` (`AgentFormRailProps`); the default Save section is not rendered when the slot is given. `approvalControl="segmented"` renders allow / ask / deny per category as a kit `Segmented` (`policy-row` / `policy-label`) posting through a hidden input under the same field name. `dirty()` joins the exposed API. The stack layout and the field names are unchanged.

- States (`src/kit/states`, #87), `docs/design/HANDOFF.md` → "Failure distinction", "Edge cases": three more `ag-*` scopes — `ag-failure` (`FailureCard`, the six named states from the shared `FAILURES` table with name, icon, signal caption, tone and action; `kind` axis fully wired, `client-offline` → `offline`), `ag-banner` (`OfflineBanner`), `ag-empty` (`EmptyState`: workspace / inbox / machines / chat / generic; `compact`, `outline`) — plus `EventsLostRow`, the connection-strip row helpers (`browserRow`, `machineRow`, `connectionRows`) and the skeleton presets (`TableSkeleton`, `CardSkeleton`, `RailSkeleton`). Every declared axis value is now wired, so the web build validates with `--strict`.
- `ai-*` fragment restyled to `docs/design/HANDOFF.md` (#86): `ai-thread` (gap 24, padding 24/32, the "Showing the last N entries · Load earlier" chip, `aria-live="polite"`), `ai-message` as a row — kit `AgentTile` avatar (persons are circles), `meta` with new `name` / `environment` (kit `EnvironmentLine`) / `time` parts and the STREAMING pill on the last assistant row mid-turn; `Thread` gains `describe`, `toolMeta`, `logHref`; `Message` gains `author` (`MessageAuthor`), `streaming`, `toolMeta`, `logHref`; `midTurn` exported. `ai-tool-call` header with `icon` (`toolIcon`), `name`, `signature`, `meta`, the phase as a `StatusPill` (PENDING · RUNNING · DONE · ERROR · DENIED; refined phase in `meta`), a border colour only for `active` / `error`, the output well folded past `OUTPUT_FOLD` (6) lines behind `more` and linking to the session `log` past `OUTPUT_LOG` (200); `ToolCall` gains `meta` and `logHref`; `elide` no longer folds lines. `ai-reasoning` collapsed as "Reasoning · Ns" behind a 14 px chevron (`seconds`, `reasoningSummary`). `ai-approval` as the approval card — `header` (`title`, `rule`), `request` well, `context` rows, three `actions` (`Allow once` amber, `Allow for this session`, `Deny`), `record` (`decisionText`), `compact` modifier, assertive announcement, buttons disabled and spinning until the ack; `ApprovalPrompt` gains `input`, `rule`, `requestedBy`, `environment`, `via`, `compact`, `decision` and drops the "Deny for session" button. `ai-composer` with the `addressing` row (`recipient` chips on `AgentTile`, `hint`, `NOBODY_HINT`), `keys` hint, an attach icon button (`attach` event), kit `Button`s (Send primary 44 px); `Composer` gains `recipients`, `hint`, `attach`. Recipes read the `--ag-*` inks with recommended fallbacks; `fragmentCss` (the streaming pulse keyframes) rides the design system's raw-CSS slot; motion off under reduced motion. `Message` no longer composes zero `Chat`.

- App component kit (`src/kit`, #85), `docs/design/HANDOFF.md` → "Components": eight `ag-*` scopes with anatomies and recipes in the fragment — `ag-pill` (`StatusPill` with one row per `TaskStatus`, machine, auth and tool phase in `PILLS`; `Tag`; `WaitReasonLine` / `waitText` in the literal core names), `ag-agent-tile` (`AgentTile`, `hueFor`, `monogramOf`; people are circles), `ag-env-line` (`EnvironmentLine`, never one part alone — EXE-06), `ag-needs-item` (`NeedsItem`, `kind` axis, `compact`), `ag-task-node` (`TaskNode`, depth rail, `selected`, a real button), `ag-connection` (`ConnectionStrip`), `ag-version` (`VersionItem`: current / proposed / past), `ag-env-card` (`EnvironmentCard` restyled: capacity meter, queued count, "Default for" tiles, auth fix line with `Re-check`; `authPill`, `authFixLine`; `environmentStatus` gains `tone`). Compositions over zero: `Button` (intents primary / default / wait / danger / icon on the daisy axes, `confirm`, `loading`, `block`), `Segmented` (ToggleGroup, `aria-pressed`, per-segment tone at 15 %), `Switch`, `ChipInput` (= `MultiSelect`), `DataTable` (column template → `<col>` widths, skeleton rows), `TimelineList`, `ConfirmDialog` (alert dialog, dependents listed, consequence label), `SectionHeading`, `Label`, `Icon` (the artboards' 34 stroke icons). Every `tone` and every kit modifier is wired; `tokens.scopes` claims the vocabulary per scope (`kitScopes`); `Ag*` aliases satisfy `componentExportName(scope)`. `kitCss` (`data-visually-hidden`) rides the design system's raw-CSS slot.

- Design system (`src/design-system`, `@agentic/ui/design-system`, #84): the `agentic` design system on zero-daisyui with the one dark theme `control-room` from `docs/design/HANDOFF.md`; `--ag-*` custom tokens; `tone` / `kind` axes and `hollow` / `outline` / `compact` / `selected` / `current` modifiers declared; daisy recipes re-tuned per scope by `withOverride` (button, fields, switch, badge, dialog, table, timeline, card, breadcrumbs, tabs, collapsible, toggle-group, skeleton, navbar); the `ai-*` fragment recipes included; compiled by `scripts/build-design-system.mjs` into `dist/ds/**` — exports `./css`, `./css/tokens`, `./register`, `./manifest.json`, `./fragment.json`; `installThemes()`. `@sigx/zero-daisyui` is a runtime dependency.
- App shell restyled to the handoff (#84): 232 px sidebar / 60 px topbar on the design-system tokens, nav `groups` (labelled `<nav>` per group) and per-item `badge`, `breadcrumb` / `actions` / `connection` / `user` slots, `flush` main, the 3 x 16 px live marker; `SHELL_BREAKPOINT` and `NavGroup` exported. The shell no longer renders `ThemeToggle`.

- Package skeleton.
- Layout tier on `data-l-*` (`src/layout`): `Stack`/`Row`/`Col` (one `stack` scope, `data-orientation`), `Spacer`, `layoutAttrs`, breakpoint-prefixed overrides (`at={{ md: … }}`), `layout.css` step table over `--space-*`; `useMediaQuery` (SSR-safe). Exported as `@agentic/ui/layout.css`.
- App shell (`src/shell`): `AppShell` (zero `Navbar` + modal `Drawer` below 768px, static sidebar above; router-agnostic `link` slot; `currentPath` → `data-state="active"`), `ThemeToggle`; `shell.css` exported as `@agentic/ui/shell.css`.
- Forms (`src/forms`, #25) on zero's `model=` form contract, each posting pre-hydration and read back by one parser: `AgentForm` (identity, skills/tools/connectors multi-select with a per-tool mode, per-category approval policy, memory, execution defaults and limits, collaborators, version reason; `submit` / `invalid` events, exposed `reset()` / `submit()`), `ConfigVersions` (history with revert, a real form per row), `EnvironmentCard` + `environmentStatus`, `SettingsForm` (IANA time zone, notification kinds, push, default environment). Models: `toAgentDraft` / `fromAgentDraft` / `agentDraftFromFormData` / `parseAgentFormData` / `validateAgentDraft` and the settings equivalents; labelled field wrappers (`TextField`, `TextareaField`, `SelectField`, `NumberField`, `SwitchField`, `MultiSelectField`).
- Zero gap: `MultiSelect` (`src/_zero-gaps`, scope `ai-multi-select`) — a `string[]` model over zero's `Combobox`, chips posting repeated hidden inputs (andtii/zero-wip#479).
- Transcript (`src/thread`, scopes `ai-thread` / `ai-message` / `ai-tool-call` / `ai-reasoning` / `ai-approval`): `Thread` over a reactive `AgentTranscript` (`role="log"`, windowed to 150 parts, stick-to-bottom, pauses on scroll-up with a frozen window, "Show earlier" / "Jump to latest"; rows keyed by message id so a sliding window patches instead of remounting), `Message` on zero `Chat` with an attribution `Badge` per author, `ToolCall` (governed `data-state` `loading | active | complete | error | closed`, phase text in `status`, collapsible input/output, sub-agent card with capability-gated Cancel), `Reasoning` on `<details>`, `ApprovalPrompt` (allow/deny × once/session → `onRespond(requestId, Decision)`), `StreamingMarkdown` on `@sigx/markdown/dom`.
- Composer (`src/composer`, scope `ai-composer`): zero `Textarea` autogrowing by line count, Enter sends / Shift+Enter breaks, `@mention` listbox (arrows, Enter/Tab pick, Escape dismiss; the textarea is its combobox — `aria-controls` / `aria-expanded` / `aria-activedescendant` on stable option ids), attachments strip stub, Send gated on `busy`/`steers`, Cancel on `canCancel`.
- Fragment (`src/fragment`, `@agentic/ui/fragment`): the six anatomies as a manifest fragment (`version: 1`) plus a recipe pack on the recommended token grammar; `"sigx-zero"` package.json field; `build` also emits `dist/fragment.json`.
